# 配置详解 / Configuration reference

面向想认真调参的人。只想装好就能玩的话，看 [README](../README.md) 第三节就够了。

---

## 1. INI 语法

与 AC8 的 `AC8PropNav` 完全一致 —— 这正是本项目刻意的设计约束，老配置改个
文件名就能继续用。

```ini
[player]
msl = {                        ; 块写法
    HomingForesightAmount = 0.7
    MaxRotationAngle      =
    MaxHomingAngle        =
    LifeTime              =
    LockonRange           =
}

qaam = 1.0                     ; 单行写法 == 只设 HomingForesightAmount
2aam = 0.9                     ; 旧写法同样有效

[enemy]
msl = { HomingForesightAmount = 0.3 }
```

规则：

* **只改填了数字的项；留空 = 保持原版。**
* 型号键按**长度降序**匹配 ⇒ 写 `4aam` 不会被 `aam` 抢走。
* 型号键大小写不敏感，会当作"武器标识里的子串"去匹配游戏数据。
* 注释用 `;` 或 `#`，允许行尾注释。
* 未知属性/段会警告并忽略，不会让整个文件失效。
* 文件是 **UTF-8 with BOM**。手工编辑时请保持编码，别让编辑器改掉它
  （BOM 丢了只是注释里的中文可能显示异常，不影响功能）。

## 2. 五个属性

| 属性 | 单位 | 作用 | 默认（留空时） |
| --- | --- | --- | --- |
| `HomingForesightAmount` | 0 – 1 | **主参数**：纯追踪 ↔ 真 PN 的混合系数 | 由 INI 出厂值决定（`msl = 0.7`） |
| `MaxRotationAngle` | 度/秒 | 每帧转角上限 | **180** |
| `MaxHomingAngle` | 度 | 导引头视场**半角**，超出即不转向 | 用游戏自己的 `startAng`（玩家 MSL = 90 ⇒ 180° 全视场） |
| `LifeTime` | 米 | 射程（≈ 存活时间 × 速度） | **未接线**，见 §5 |
| `LockonRange` | 米 | HUD 锁定圈距离（只对玩家） | **未接线**，见 §5 |

### 2.1 `HomingForesightAmount`（最重要的旋钮）

`0` = 纯追踪：每帧朝目标当前位置转，但转角仍受 `MaxRotationAngle` 限制 ——
也就是"用本模组的限速重跑原版追尾逻辑"，可以直接当 A/B 基线。
`1` = 完整比例引导（`ω = N · λ̇`）。中间值在**两个结果方向之间沿大圆插值**。

⚠️ **留空 ≠ 写 0**。留空表示"这个型号完全交还原版"；写 `0` 表示"接管，但用纯追踪"。
想彻底关掉整个模组用 `[runtime] GuidanceOverride = 0`。

### 2.2 `MaxRotationAngle`

真实单位是"度/秒"，按引擎自己的帧率常量（本版本 60）折算成每帧转角，所以
**填 90 就是 90°/s**。留空时的内置默认是 **180°/s**（= 3°/帧）。这是本模组接管后唯一的转向限速 —— 原版用数据记录里的
`lead` 字段当限速（玩家 MSL 是 40），两者不是同一个量。

### 2.3 `MaxHomingAngle`

**半角**。`90` 意味着 ±90°（180° 全视场），`360` 意味着几乎永远不会因为视场而
脱锁 —— 这是单一项里最"超模"的改动。

超出视场时：**不写位置**（不转向），但不清除锁定。目标转回视场就继续制导。

## 3. `[enemy]` 段

ACZ 里每种武器通常只有**一份**参数记录（敌我共用）。所以 `[enemy]` 的实际效果是
"非玩家发射的导弹"：敌机**和僚机**都算。

* 想让敌人保持原版：把整个 `[enemy]` 段删掉或注释掉。
* 出厂值 `[enemy] msl = 0.3`，明显弱于玩家的 0.7 —— 你能甩掉敌弹，敌机比较难
  甩掉你的。

## 4. `[runtime]` 扩展段（可选）

```ini
[runtime]
LogLevel         =        ; 留空 = 1（几乎不写日志）
GuidanceOverride = 1      ; 总开关：0 = 完全关掉比例引导
PnGain           = 4      ; 导航常数 N
TerminalZone     = 0      ; 0 = 全程 PN；>0 = 末端该半径（米）内交还原版
```

| 键 | 取值 | 说明 |
| --- | --- | --- |
| `LogLevel` | 0 / 1 / 2 | `0` = 完全不建日志文件；`1`（默认）= 启动+钩子状态+警告错误；`2` = 详细，含每 2 秒统计与逐条修正明细。**报 bug 时设 2。** |
| `GuidanceOverride` | 0 / 1 | 模组总开关。`0` = 完全不接管。 |
| `PnGain` | 0.5 – 12 | PN 的导航常数 `N`。经典值 4；调大更早转弯更激进，调小更平滑。超过 6 会明显过冲。 |
| `TerminalZone` | 0 – 2000 | `0`（默认）= 全程比例引导。正数 = 进入该半径（米）后把最后进场交还原版制导，**仅供 A/B 对比**，不是修复。 |
| `DryRun` | 0 / 1 | 只计算、只写日志，不写游戏内存。 |
| `TickHz` | 1 – 1000 | 接管线程的 tick 频率。默认 120。 |
| `RequireVerifiedOffsets` | 0 / 1 | 静态参数路径专用，默认 1（没验证过结构就不写内存）。 |

其余 `[runtime]` 项（`Probe` / `RingSurvey` / `HwWatch` / `HookRva` /
`HookSignature` / `HookArgIndex` / `LeadScale` / `LeadMode` / `Entity*Offset` …）
是**逆向与诊断用的开发者选项**，正常游玩和正常调参都不需要碰。
`LeadScale` / `LeadMode` 尤其如此：它们只服务于旧的静态参数路径（在当前正式版
游戏上默认不生效，日志会说明），不是控制手感的东西 —— 手感靠 `HomingForesightAmount`。

INI 文件里每一项都有中英双语注释。

## 5. 尚未接线的属性

`LifeTime` 和 `LockonRange` 在**普通 MSL 的比例引导路径**上没有生效：

* 射程/寿命 kill 仍由原版执行（`P+0x14 × 5.12` 的行程判定）；
* HUD 锁定圈仍是原版距离。

原因：普通 MSL 的 PN 钩子只改导弹的**位置与姿态**，不改 `P`（武器参数记录）本身；
而这两项要改的是记录里的字段。填了不会崩，只是不生效。

特殊武器路径同理 —— 特武的参数按 `[player] msl` 的配置驱动，因为引擎不告诉
模组某个导弹槽属于哪个型号。

## 6. 调参建议速查

| 想要的效果 | 怎么改 |
| --- | --- |
| 更强、更"粘人" | `HomingForesightAmount` 往 1 靠；`MaxRotationAngle` 调到 180 |
| 几乎甩不掉 | `MaxHomingAngle = 360`（单这一项就足够强） |
| 保留原版手感但更聪明 | `HomingForesightAmount = 0.3` 左右 |
| 只让玩家受益 | 删掉整个 `[enemy]` 段 |
| 觉得敌人太强 | `[enemy] msl` 调低，或删掉该段 |
| 完全关掉 | `[runtime] GuidanceOverride = 0` |
